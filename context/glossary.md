# 공통 용어 사전

> 도메인을 가리지 않고 프로젝트 전체에서 쓰이는 용어입니다.
> 도메인별 용어는 `context/{도메인}/glossary.md`를 참조하세요.

| 용어 | 설명 |
|------|------|
| RGR 사이클 | RED-GREEN-REFACTOR. 실패 테스트 작성 → 최소 구현 → 정리의 반복 단위 |
| AC | Acceptance Criteria. 수용 기준. "~일 때 ~해야 한다" 형태로 판정 가능해야 한다 |
| BR | Business Rule. 이 프로젝트에서 도메인 규칙 식별자 접두어 (BR-01 등) |
| FR / NFR | 기능 요구사항 / 비기능 요구사항 |
| verify 게이트 | 테스트 명령을 실제 실행해 0 failures를 확인해야 커밋·PR로 진입할 수 있는 관문 |
