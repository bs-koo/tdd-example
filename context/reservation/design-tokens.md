# reservation 디자인 토큰 — 톤 기준 (SSOT)

> 이 화면의 색·타이포·간격·라운드가 **왜 그 값인지**를 담는다.
> 값의 코드 원본은 [`frontend/src/styles/tokens.css`](../../frontend/src/styles/tokens.css)이며, 이 문서는 그 값의 **근거와 금지 사항**을 관리한다.
> 값을 바꾸려면 두 곳을 함께 고친다.

수립: 2026-08-28 (gx-redesign 파이프라인) · 상태: 검수 승인(Approved)

## 0. 이 문서를 읽어야 하는 때

- 이 화면에 **새 요소를 추가**할 때 — 어떤 색·크기를 써야 하는지
- **토큰 값을 바꾸려** 할 때 — 무엇이 깨지는지 (§5·§6)
- 다른 화면으로 이 톤을 **확장**할 때

리디자인 이전에는 이 프로젝트에 스타일시트가 0줄이었다. 보존할 시각 부채가 없어 백지에서 수립했으므로, 이 문서가 유일한 톤 기준이다.

## 1. 원칙 5가지

| | |
|---|---|
| **무채색 기반 + 포인트 1색** | 파랑이 보이면 "지금 상호작용 중"이라는 뜻 하나로만 읽힌다 |
| **상태는 색이 아니라 면과 대비로** | 슬롯 가용/점유/지난시간에 채도를 쓰지 않는다. 색약 사용자에게도 서열이 성립한다 |
| **그림자 최소, 경계는 보더로** | 그림자는 카드 1단 + 다이얼로그 1단, 총 2종뿐 |
| **여백에 리듬** | 전부 같은 간격으로 깔지 않는다. 섹션 48 / 카드 내부 24 / 셀 간 4px |
| **한 화면 하나의 과업** | 보드가 유일한 주 과업. 다이얼로그가 열리면 배경은 오버레이로 비활성 |

레퍼런스는 토스 제품군의 **디자인 원칙**이다. 토스의 로고·전용 서체(Toss Product Sans)·고유 일러스트·브랜드 컬러 코드는 재현하지 않는다 — 검수에서 저작권 가드 위반 0건으로 확인됐다.

## 3. 타이포

`--ff-sans`: **Pretendard Variable** → Pretendard → `-apple-system` → `Apple SD Gothic Neo`(macOS) → `Malgun Gothic`(Windows) → `Noto Sans KR` → `Segoe UI`

CDN(jsdelivr)이 사내망에서 차단돼도 OS 한글 서체로 폴백해 깨지지 않는다. Google Fonts만 허용되는 환경이면 `Noto Sans KR` 400/500/700으로 교체하고 **나머지 토큰은 그대로 둔다.**

| 역할 | 크기 / 행간 | 굵기 |
|---|---|---|
| `--fs-title` | 28px / 1.35 (`-0.02em`) | 700 |
| `--fs-section` | 20px / 1.4 | 600 |
| `--fs-body` | 16px / 1.6 | 400 |
| `--fs-sm` | 14px / 1.5 | 500 |
| `--fs-caption` | 13px / 1.45 | 400 |

- `button, input, select, textarea { font: inherit }` — UA 기본 13.33px 부산물 제거
- 시간 축·슬롯 시각에 `font-variant-numeric: tabular-nums`
- **`--fs-caption` 13px은 눈금·범례·메타 라벨 전용.** 본문·슬롯 내용에는 쓰지 않는다

## 4. 간격 · 라운드 · 그림자 · 모션 · 격자

```
간격   4 · 8 · 12 · 16 · 24 · 32 · 48 · 64px    (sp-1 … sp-8)
라운드 6(슬롯) · 10(버튼·입력) · 16(카드) · 20(다이얼로그) · 999(범례 점)
그림자 카드 1단 + 다이얼로그 1단, 오버레이 rgba(16,24,40,.44)
모션   120ms / 180ms · cubic-bezier(.2,.7,.3,1) · prefers-reduced-motion에서 0s
격자   --room-col 180px(1440) / 148px(1024) · --slot-min 44px
```

**슬롯 최소 타깃 44×44px는 줄이지 않는다.** 1024에서 19열 합이 1012px로 뷰포트를 넘어 가로 스크롤이 생기지만, 44px를 줄이면 진단 A-2(클릭 지점이 눈에 안 띔)가 되살아난다. 스크롤 시 방 이름 열은 `position: sticky`로 남는다.

## 5. 인수한 한계 — WCAG 1.4.11 (승인자 결정)

슬롯 3면의 **상호 대비가 3:1에 닿지 않는다.**

| 쌍 | 실측 | 요구 |
|---|---|---|
| 가용 ↔ 지난 시간 | 1.16:1 | 3:1 |
| 지난 시간 ↔ 점유 | 1.20:1 | 3:1 |
| 가용 ↔ 점유 | 1.39:1 | 3:1 |
| 가용 보더 ↔ 카드 | 1.46:1 | 3:1 |

**왜 인수했나.** 밝은 무채색 3면으로 3:1을 만들려면 한 면이 중간 회색(`#959595` 수준)이 되어야 하고, 이는 "깔끔하고 밝은" 팔레트 방향 자체를 버리는 일이다. 72칸 전부에 3:1 보더를 두면 격자가 읽히지 않는다.

**대신 무엇을 했나.** 밝기 간격을 최대한 벌리고(1차 1.06 → 1.16), **점선이라는 두 번째 채널**을 지난 시간에 넣었으며, 범례 스와치를 16px로 키워 슬롯과 동일한 면·보더·보더모양을 쓰게 했다. 세 상태 모두 밝기 외 채널을 갖는다(§2.3).

**뒤집으려면**: 지난 시간을 중간 회색으로 내리면 3:1이 성립한다. 팔레트 방향과 접근성 중 어느 쪽을 택할지의 문제다.

## 6. 토큰을 바꾸기 전에 — 금지·주의

### 6.1 값 자체의 제약

- **`--c-busy-bg`를 이 이상 어둡게 하지 말 것** — 그 위 `.slot__purpose`(`--c-text-2`)의 대비가 4.52:1로 AA 여유가 0.02:1뿐이다.
- **`--c-text-3`을 밝게 하지 말 것** — 시간 축·정책 안내·정원층·기준시각 7개소가 동시에 AA 미달로 넘어간다. 이 값들은 리디자인의 성과물 자체다.
- `--c-past-bd`를 바꾸면 `.slot[data-state='past']:hover`의 보더도 함께 봐야 한다 — 호버가 대비를 낮추는 역전이 실제로 발생한 적이 있다.

### 6.2 마크업의 제약 — 프론트 테스트 108건이 고정한 것

디자인을 바꾸다 이 선을 넘으면 테스트가 깨진다. 상세는 [`test-scenarios.md`](test-scenarios.md).

| 불가 | 근거 |
|---|---|
| `TimeSlotGrid` 안에 **버튼 추가** | `getAllByRole('button')` 정확히 72개 |
| 방 이름 **이중 렌더**(반응형 두 벌 DOM) | `getByText('대회의실')` 단수 조회 12곳 → 반응형은 **축 회전**으로 처리 |
| 정원·층을 방 이름과 **한 노드에 합치기** | `getByText` exact 매칭 |
| 점유 칸 **병합**(`colspan`/`grid-column: span`) | 09:00–10:00 예약은 09:30 칸에도 이름 텍스트 필요 → 반복 텍스트는 **`visibility:hidden`만** (`display:none`·노드 제거 금지) |
| 날짜 입력 `type="date"` | 부분 입력 `2026-08`이 화면에 보여야 함 (AC-38) |
| 종료 시각 `<select>` | `user.clear()` + `user.type()` → `<input list>`+`<datalist>`는 가능 |
| 취소창에 텍스트 입력 추가 | `queryByRole('textbox')` 부재 단언 |
| 다이얼로그 버튼 이름 `확인`·`닫기` 변경 | 5개 파일 9곳 |
| 상시 노출·로딩·인라인 문구에 `role="alert"` | 정상 상태 alert 0개 단언 → `role="status"`·무-role만 |

### 6.3 안티-텔 — 이제 지켜야 할 제약

리디자인 이전에는 장식이 없어 위반이 0이었다. 지금은 지켜야 한다:
그래디언트 텍스트 · 색 글로우 · 카드 인 카드 · side-tab 액센트 보더 · eyebrow 칩 · 동일 카드 3개 그리드 · 과대 h1 · 펄싱 점 — **전부 금지.**

*(제작 중 오류 배너의 `border-left: 3px solid danger`가 side-tab 액센트로 판정돼 균일 1px 보더로 교체된 전례가 있다.)*
